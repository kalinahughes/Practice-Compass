WHAT WORKS
• Automatic placement countdown and week/day tracking from 20 July 2026
• 7.25 hour standard day and 500 hour progress tracking
• JCU assessment dashboard in plain English
• Guided daily journaling with examples, prompts and theory/method memory joggers
• Learning Plan coach and evidence counts
• Theory coach
• Evidence bank
• Weekly review
• Wellbeing prompts
• Local browser saving
• Printable journal export
• JSON backup export
• Add to iPhone Home Screen

HOW TO USE ON PHONE
1. Unzip this folder.
2. Upload the unzipped folder to Netlify Drop or Vercel Drop.
3. Open the generated site link in Safari.
4. Tap Share > Add to Home Screen.

IMPORTANT
Data is stored in the browser on that device. Do not clear website data. Export regular backups.
Never enter identifiable consumer information.
